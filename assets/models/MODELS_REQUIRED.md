# Model Files Required / Các file mô hình cần thiết

> **WARNING**: These model files are NOT included in the repository due to their large size (~350MB each).
> You must download them manually before building the app.

## Qwen2.5-0.5B-Instruct (INT4 Quantized)

**File name:** `qwen2.5-0.5b-instruct-q4_k_m.gguf`

**Download:**
- Hugging Face: https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF
- Direct file: `qwen2.5-0.5b-instruct-q4_k_m.gguf` (~350MB)

**Instructions:**
1. Download the `.gguf` file from the link above
2. Place it in this directory: `assets/models/qwen2.5-0.5b-instruct-q4_k_m.gguf`
3. Make sure to add the file to your local `pubspec.yaml` assets section (already done)

> **LƯU Ý**: Các file mô hình AI không được lưu trong repository vì kích thước quá lớn (~350MB).
> Bạn cần tải về thủ công trước khi build app.
